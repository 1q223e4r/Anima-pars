# ANIMA PARS — 쇼핑몰 포트폴리오 사이트

포트폴리오용 가상 의류 브랜드의 웹사이트예요.
서버 없이 HTML·CSS·자바스크립트 파일만으로 동작해서, 무료 호스팅에 그대로 올릴 수 있어요.

## 폴더 구조

```
anima-pars/
├─ index.html        홈
├─ shop.html         컬렉션(상품 목록·필터·정렬·검색)
├─ product.html      상품 상세 (product.html?id=AP-001 처럼 id로 상품을 고름)
├─ cart.html         장바구니
├─ robots.txt        검색엔진 안내 파일
├─ sitemap.xml       검색엔진에 제출할 페이지 목록
├─ brand/            옷 마킹용 '별 달린 A' 로고 (원단 색별 4가지, SVG·PNG)
└─ assets/
   ├─ css/style.css  모든 페이지의 디자인
   ├─ img/
   │  ├─ favicon.svg   브라우저 탭 아이콘
   │  ├─ star-mark.svg 별 심볼 (헤더·푸터의 글자 로고 옆)
   │  └─ emblem.svg    엠블럼 (모든 페이지 맨 아래)
   └─ js/
      ├─ data.js     상품 데이터 (상품을 바꾸려면 이 파일만 수정)
      ├─ common.js   헤더 메뉴·검색, 장바구니 저장, 상품 카드 그리기
      ├─ home.js     홈: 신상품, 뉴스레터
      ├─ shop.js     컬렉션: 필터·정렬·검색
      ├─ product.js  상품 상세: 색상·사이즈 선택, 장바구니 담기
      └─ cart.js     장바구니: 수량 변경, 합계·배송비
```

## 내 컴퓨터에서 미리 보기

압축을 풀고 `index.html`을 더블클릭하면 브라우저에서 열려요.
장바구니는 브라우저 저장소(localStorage)에 저장돼서, 페이지를 옮겨도 그대로 남아 있어요.

## 인터넷에 올리기 (Vercel, 무료)

1. GitHub에 새 저장소를 만들고 이 폴더 **안의** 파일을 전부 올려요.
   (`index.html`이 저장소 맨 위에 있어야 해요.)
2. vercel.com에 GitHub 계정으로 가입한 뒤, 새 프로젝트를 만들고 방금 만든 저장소를 골라 배포(Deploy)해요.
3. `프로젝트이름.vercel.app` 같은 주소가 생기면 끝이에요. 이후 GitHub에 올린 수정은 자동으로 반영돼요.

Git이 어렵다면 Netlify의 드롭 기능(app.netlify.com/drop)에 이 폴더를 끌어다 놓아도 바로 주소가 생겨요.

## 구글 검색에 등록하기

1. `sitemap.xml`과 `robots.txt` 안의 `YOUR-SITE.vercel.app`을 실제 주소로 바꾸고 다시 올려요.
2. Google Search Console에서 속성을 추가해요. 주소 형식은 'URL 접두어'를 고르고 사이트 주소를 넣으면 돼요.
3. 소유권 확인은 'HTML 태그' 방식이 가장 쉬워요.
   안내받은 `<meta name="google-site-verification" ...>` 한 줄을 `index.html`의 `<head>` 안에 붙여 넣고 다시 배포한 뒤 '확인'을 눌러요.
4. 'Sitemaps' 메뉴에서 `sitemap.xml`을 제출하고, 'URL 검사'에서 첫 페이지의 색인 생성을 요청해요.

검색 결과에 뜨기까지는 시간이 걸리고, 모든 페이지가 올라간다는 보장은 없어요.

## 상품 바꾸기

상품 정보는 `assets/js/data.js` 한 곳에만 있어요.
`PRODUCTS` 목록의 이름·가격·설명을 고치거나 새 상품을 추가하면 모든 페이지에 반영돼요.
지금 들어 있는 상품 설명과 사이즈 수치는 예시예요.

카테고리마다 붙는 라틴어 동물 이름(아우터 Lupus·늑대, 데님 Apis·벌, 셔츠 Mustela·족제비, 스웨트 Leo·사자, 티셔츠 Felis·고양이, 액세서리 Hirundo·제비)은
같은 파일의 `CATEGORIES`에서 바꿀 수 있어요. 상품 행택과 상세 페이지에 표시되고, 검색어로도 찾을 수 있어요.

옷 그림에 들어가는 별 달린 A 자수는 같은 파일 `GARMENTS`의 `mark` 값(가운데 위치·높이)으로 옷마다 정해요.
지금은 재킷 두 벌의 가슴 주머니, 캡 앞판 패치, 토트백 앞면에 들어가 있고, `mark`를 지우면 그 옷에서는 빠져요.
실 색은 원단이 밝으면 에스프레소+황토, 어두우면 크림+밝은 황토로 자동으로 바뀌어요.

## 로고 파일

- 글자 로고(ANIMA PARS)와 별 심볼은 각 HTML 맨 위의 `<symbol>`에 들어 있어요. 색과 크기는 `style.css`의 로고 부분에서 바꿔요.
- `assets/img/star-mark.svg`: 별 심볼만 따로 쓸 때 쓰는 파일
- `assets/img/emblem.svg`: 모든 페이지 맨 아래에 들어가는 엠블럼
- `brand/`: 옷에 마킹할 '별 달린 A'. 밝은 원단·어두운 원단용 2색·1색 4가지예요. 인쇄·자수 업체에는 SVG를 주세요.

## 공개하기 전에 확인할 것

- 상단 바와 푸터의 '포트폴리오용 가상 브랜드' 문구는 지우지 마세요. 진짜 쇼핑몰로 오해받지 않게 해 줘요.
- '주문하기'와 '구독하기'는 실제로 아무것도 보내거나 저장하지 않아요. 실제 결제나 이메일 수집을 붙이려면 사업자등록·통신판매업 신고, 개인정보 처리방침이 필요해요.
- 브랜드 이름을 공개적으로 쓸 거라면 키프리스(KIPRIS)에서 상표가 이미 등록돼 있는지 확인해 보세요.
